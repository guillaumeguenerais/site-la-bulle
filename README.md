# La Bulle — Lunchbar · site vitrine

Site one-page autonome (HTML/CSS/JS dans `index.html`, aucune dépendance à installer).
Ouvrir `index.html` dans un navigateur, ou déposer le dossier tel quel chez n'importe quel hébergeur statique (domaine cible : labulle.re).

## Structure

```
index.html            site complet (HTML + CSS + JS inline)
assets/photos/        photos compressées (max 1200 px, JPEG ~80 %)
```
